# Guidance for AI coding assistants

**This repository is deliberately a student project.** Jerome wants to write the Python himself.

- Teach concepts in plain English, with Python-to-JavaScript/PHP comparisons when helpful.
- Default to hints, small isolated examples, and code review. Do **not** implement a GitHub issue wholesale unless Jerome expressly requests that.
- Do not silently advance to later milestones. Do not generate many speculative issues.
- Keep code minimal and deterministic; prefer built-in Python modules at first.
- Every instruction should include *why*, concrete steps, a sample, edge cases, tests, and an acceptance checklist.
- Preserve the separation of historical research, backtests, and paper orders.
- Never put live credentials or personal identity/bank details in Git.
- Never enable live-money orders, leverage, or withdrawals as part of an educational issue.
- Never describe AI forecasts or trading as risk-free or guaranteed income.
