# Getting Help

Learning Python? You are in the right place.

1. Start with the [learning guide](docs/LEARNING_GUIDE.md) and [glossary](docs/GLOSSARY.md).
2. Find your current step in the [roadmap](docs/ROADMAP.md).
3. Search [existing GitHub issues](https://github.com/Thavarshan/wallstreet/issues).
4. Open a **Python learning question** using the issue template. Include your code attempt, what you expected, and the error (with all secrets removed).

For bugs or proposals, choose the relevant issue template. For sensitive vulnerabilities, use the private route in [SECURITY.md](SECURITY.md).

**Scope:** This project can help with Python code, reproducible research, and paper-trading simulations. It does not provide personal investment advice, broker support, or guaranteed returns. Maintainer responses are voluntary, so response times may vary.
